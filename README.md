# Calculator Project

This is a simple calculator application built as part of a learning journey into software development. The project was created by following a tutorial, which provided step-by-step guidance on how to implement basic calculator functionality using clean and structured code.

## 📚 About This Project

The main goal of this project was educational. By following a tutorial, I was able to:

- Understand the fundamentals of building a user interface.
- Learn how to handle user input and events.
- Implement arithmetic logic in a clear and maintainable way.
- Gain insight into structuring small-scale applications.

While the core logic and structure were based on a tutorial, the experience helped solidify my understanding of programming concepts and development workflows.

## 🛠️ Features

- Addition, subtraction, multiplication, and division
- Responsive and intuitive interface
- Clear and reset functionality
